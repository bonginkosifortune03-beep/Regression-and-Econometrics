# Regression-and-Econometrics
Regression and econometrics in SAS (STK310, University of Pretoria): multiple regression, dummy variables, Chow test, multicollinearity, heteroscedasticity, autocorrelation and distributed lag models.
The folder has following projects:
SAS basics and simple regression,
Multiple regression and diagnostics,
Nonlinear models and transformations,
Dummy variables and the Chow test,
Multicollinearity,
Heteroscedasticity,
Autocorrelation and Cochrane-Orcutt,
Distributed lag models.
